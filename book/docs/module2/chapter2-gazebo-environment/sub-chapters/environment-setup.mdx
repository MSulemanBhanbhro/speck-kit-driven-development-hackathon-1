# Environment Setup and Configuration

Setting up a Gazebo simulation environment requires careful configuration of various parameters to ensure realistic and efficient simulation. This chapter covers the essential aspects of configuring Gazebo environments for humanoid robotics applications.

## Gazebo Installation and Dependencies

### System Requirements

Before configuring Gazebo environments, ensure your system meets the requirements:
- **Operating System**: Ubuntu 18.04/20.04/22.04 or equivalent Linux distribution
- **Graphics**: OpenGL 2.1+ compatible GPU with dedicated VRAM
- **Memory**: 8GB+ RAM for complex simulations
- **CPU**: Multi-core processor for parallel physics computation

### Installation Process

```bash
# Install Gazebo with ROS integration
sudo apt update
sudo apt install gazebo libgazebo-dev

# For ROS2 integration
sudo apt install ros-humble-gazebo-ros-pkgs
```

### Environment Variables

Configure environment variables for optimal Gazebo performance:
```bash
export GAZEBO_MODEL_PATH=$GAZEBO_MODEL_PATH:~/.gazebo/models:/path/to/custom/models
export GAZEBO_RESOURCE_PATH=$GAZEBO_RESOURCE_PATH:~/.gazebo/worlds:/path/to/custom/worlds
export GAZEBO_PLUGIN_PATH=$GAZEBO_PLUGIN_PATH:~/.gazebo/plugins
```

## World Configuration Parameters

### Physics Engine Configuration

The physics engine is the core of any Gazebo simulation. Configure it properly for realistic results:

```xml
<physics type="ode">
  <!-- Time stepping parameters -->
  <max_step_size>0.001</max_step_size>          <!-- Physics update interval (seconds) -->
  <real_time_update_rate>1000.0</real_time_update_rate>  <!-- Updates per second -->
  <real_time_factor>1.0</real_time_factor>      <!-- Simulation speed multiplier -->

  <!-- Gravity settings -->
  <gravity>0 0 -9.8</gravity>

  <!-- ODE-specific parameters -->
  <ode>
    <solver>
      <type>quick</type>
      <iters>10</iters>                          <!-- Solver iterations -->
      <sor>1.3</sor>                             <!-- Successive over-relaxation -->
    </solver>
    <constraints>
      <cfm>0.0</cfm>                             <!-- Constraint force mixing -->
      <erp>0.2</erp>                             <!-- Error reduction parameter -->
      <contact_max_correcting_vel>100.0</contact_max_correcting_vel>
      <contact_surface_layer>0.001</contact_surface_layer>
    </constraints>
  </ode>
</physics>
```

### Rendering Configuration

Optimize rendering for visual quality and performance:

```xml
<scene>
  <ambient>0.4 0.4 0.4 1.0</ambient>            <!-- Ambient light color -->
  <background>0.7 0.7 0.7 1.0</background>      <!-- Background color -->
  <shadows>true</shadows>                        <!-- Enable/disable shadows -->

```

## Model Configuration in Gazebo

### Linking URDF Models to Gazebo

When using URDF models in Gazebo, add Gazebo-specific tags:

```xml
<!-- In URDF file -->
<link name="link_name">
  <collision name="collision">
    <geometry>
      <box><size>0.1 0.1 0.1</size></box>
    </geometry>
  </collision>
  <visual name="visual">
    <geometry>
      <box><size>0.1 0.1 0.1</size></box>
    </geometry>
  </visual>
  <inertial>
    <mass value="1.0"/>
    <inertia ixx="0.01" ixy="0.0" ixz="0.0" iyy="0.01" iyz="0.0" izz="0.01"/>
  </inertial>
</link>

<!-- Gazebo-specific properties -->
<gazebo reference="link_name">
  <mu1>0.3</mu1>                                 <!-- Friction coefficient 1 -->
  <mu2>0.3</mu2>                                 <!-- Friction coefficient 2 -->
  <kp>1000000.0</kp>                             <!-- Contact stiffness -->
  <kd>100.0</kd>                                 <!-- Contact damping -->
  <maxVel>1.0</maxVel>                           <!-- Maximum contact velocity -->
  <minDepth>0.001</minDepth>                     <!-- Penetration depth tolerance -->
  <material>Gazebo/Blue</material>               <!-- Visual material -->
</gazebo>
```

### Sensor Configuration

Configure sensors with appropriate noise models and parameters:

```xml
<gazebo reference="camera_link">
  <sensor name="camera" type="camera">
    <update_rate>30.0</update_rate>
    <camera name="head">
      <horizontal_fov>1.047</horizontal_fov>      <!-- 60 degrees in radians -->
      <image>
        <width>640</width>
        <height>480</height>
        <format>R8G8B8</format>
      </image>
      <clip>
        <near>0.1</near>
        <far>100</far>
      </clip>
      <noise>
        <type>gaussian</type>
        <mean>0.0</mean>
        <stddev>0.007</stddev>
      </noise>
    </camera>
    <plugin name="camera_controller" filename="libgazebo_ros_camera.so">
      <frame_name>camera_optical_frame</frame_name>
      <min_depth>0.1</min_depth>
      <max_depth>100.0</max_depth>
    </plugin>
  </sensor>
</gazebo>
```

## Environment Lighting and Visual Effects

### Sun and Lighting Configuration

Configure realistic lighting for the environment:

```xml
<world name="my_world">
  <!-- Sun configuration -->
  <include>
    <uri>model://sun</uri>
  </include>

  <!-- Custom lighting -->
  <light name="main_light" type="directional">
    <pose>0 0 10 0 0 0</pose>
    <diffuse>0.8 0.8 0.8 1</diffuse>
    <specular>0.2 0.2 0.2 1</specular>
    <attenuation>
      <range>1000</range>
      <constant>0.9</constant>
      <linear>0.01</linear>
      <quadratic>0.001</quadratic>
    </attenuation>
    <direction>-0.3 0.3 -1.0</direction>
  </light>
</world>
```

### Atmospheric Effects

Add atmospheric effects for enhanced realism:

```xml
<scene>
  <fog type="linear">
    <color>0.8 0.8 0.8 1</color>
    <density>0.01</density>
    <start>1</start>
    <end>100</end>
  </fog>
</scene>
```

## Performance Optimization

### Level of Detail (LOD)

Configure LOD for complex models:

```xml
<model name="complex_model">
  <!-- High detail for close objects -->
  <link name="detailed_mesh">
    <visual name="high_detail">
      <geometry>
        <mesh><uri>model://complex_model/meshes/detailed.dae</uri></mesh>
      </geometry>
    </visual>
    <collision name="high_detail_collision">
      <geometry>
        <mesh><uri>model://complex_model/meshes/detailed_collision.dae</uri></mesh>
      </geometry>
    </collision>
  </link>

  <!-- Simplified for distant objects -->
  <link name="simplified_mesh">
    <visual name="low_detail">
      <geometry>
        <mesh><uri>model://complex_model/meshes/simplified.dae</uri></mesh>
      </geometry>
    </visual>
    <collision name="low_detail_collision">
      <geometry>
        <mesh><uri>model://complex_model/meshes/simplified_collision.dae</uri></mesh>
      </geometry>
    </collision>
  </link>
</model>
```

### Occlusion Culling

Enable occlusion culling for complex scenes:

```xml
<scene>
  <grid>false</grid>
  <shadows>true</shadows>
  <sky>
    <clouds>
      <speed>0.6</speed>
      <direction>0.3 0.7</direction>
      <humidity>0.5</humidity>
      <mean_size>0.5</mean_size>
    </clouds>
  </sky>
</scene>
```

## Custom Plugins Configuration

### World Plugins

Create custom world plugins for specialized behavior:

```xml
<plugin name="custom_world_plugin" filename="libcustom_world_plugin.so">
  <update_rate>100.0</update_rate>
  <parameter_name>parameter_value</parameter_name>
  <!-- Additional parameters as needed -->
</plugin>
```

### Model Plugins

Configure model-specific plugins:

```xml
<gazebo reference="robot_name">
  <plugin name="robot_controller" filename="libgazebo_ros_control.so">
    <robotNamespace>/robot_name</robotNamespace>
    <robotSimType>gazebo_ros_control/DefaultRobotHWSim</robotSimType>
  </plugin>
</gazebo>
```

## Configuration Best Practices

### File Organization

Organize your configuration files systematically:
```
~/.gazebo/
├── worlds/
│   ├── my_world.world
│   └── other_worlds/
├── models/
│   ├── my_robot/
│   │   ├── model.sdf
│   │   └── meshes/
│   └── other_models/
└── plugins/
    └── custom_plugins.so
```

### Parameter Validation

Always validate your configuration parameters:
1. Check physics stability (no jittering or unrealistic motion)
2. Verify sensor data quality and update rates
3. Monitor real-time factor and performance metrics
4. Test collision detection accuracy

### Documentation

Maintain clear documentation of configuration parameters:
- Physics parameters and their rationale
- Model-specific configurations
- Performance optimization settings
- Known issues and workarounds

Proper environment configuration is crucial for achieving realistic and efficient simulations. Following these guidelines will help you create well-optimized Gazebo environments suitable for humanoid robotics development and testing.
