# Performance Analysis and Optimization

Performance analysis and optimization are critical for creating efficient and scalable simulation environments. This chapter explores comprehensive techniques for monitoring, analyzing, and optimizing simulation performance in Gazebo, with specific focus on large-scale and real-time robotics applications.

## Performance Metrics and Monitoring

### Key Performance Indicators (KPIs)

Understanding the right metrics is crucial for effective performance optimization:

#### Real-time Factor (RTF)

The real-time factor measures simulation speed relative to real time:

```bash
# Monitor RTF in Gazebo
gz stats

# Expected output:
# Time: 10.00s Real Time Factor: 0.850
# This means simulation runs at 85% of real-time speed
```

#### Update Rates and Frequencies

Monitor different update rates for performance analysis:

```bash

# Monitor sensor update rates
rostopic hz /robot/camera/image_raw
rostopic hz /robot/scan
rostopic hz /robot/imu/data

# Monitor controller update rates
```


#### Custom Performance Plugin

Create a comprehensive performance monitoring plugin:

```cpp
#include <gazebo/gazebo.hh>
#include <gazebo/physics/physics.hh>
#include <chrono>

namespace gazebo
{
  class ComprehensivePerformanceMonitor : public WorldPlugin
  {
    public: void Load(physics::WorldPtr _world, sdf::ElementPtr _sdf)
    {
      this->world = _world;
      this->physics = this->world->Physics();

      // Initialize timing
      this->start_time = std::chrono::high_resolution_clock::now();
      this->last_update = this->start_time;

      // Load configuration
      if (_sdf->HasElement("update_rate"))
        this->update_rate = _sdf->Get<double>("update_rate");
      else
        this->update_rate = 1.0;

      // Initialize statistics
      this->update_count = 0;
      this->total_update_time = 0.0;

      // Connect to update
      this->update_connection = event::Events::ConnectWorldUpdateBegin(
          boost::bind(&ComprehensivePerformanceMonitor::OnUpdate, this));

      // Connect to periodic monitoring
      this->timer_connection = event::Events::ConnectSimUpdate(
          boost::bind(&ComprehensivePerformanceMonitor::OnTimer, this));
    }

    public: void OnUpdate()
    {
      auto start = std::chrono::high_resolution_clock::now();

      // Perform update operations
      this->performUpdateOperations();

      auto end = std::chrono::high_resolution_clock::now();
      auto duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);

      this->total_update_time += duration.count() / 1000.0; // Convert to milliseconds
      this->update_count++;
    }

    public: void OnTimer()
    {
      auto current_time = std::chrono::high_resolution_clock::now();
      auto elapsed = std::chrono::duration_cast<std::chrono::seconds>(
          current_time - this->start_time);

      if (elapsed.count() % static_cast<int>(1.0 / this->update_rate) == 0)
      {
        this->logPerformanceMetrics();
      }
    }

    private: void logPerformanceMetrics()
    {
      // Calculate real-time factor
      common::Time sim_time = this->world->SimTime();
      double sim_seconds = sim_time.Double();
      auto current_time = std::chrono::high_resolution_clock::now();
      auto real_elapsed = std::chrono::duration_cast<std::chrono::milliseconds>(
          current_time - this->start_time);
      double real_seconds = real_elapsed.count() / 1000.0;

      double rtf = sim_seconds / real_seconds;

      // Calculate average update time
      double avg_update_time = (this->update_count > 0) ?
          this->total_update_time / this->update_count : 0.0;

      // Log metrics
      gzdbg << "Performance Metrics:" << std::endl;
      gzdbg << "  Real-time Factor: " << rtf << std::endl;
      gzdbg << "  Average Update Time: " << avg_update_time << " ms" << std::endl;
      gzdbg << "  Update Count: " << this->update_count << std::endl;
      gzdbg << "  Simulation Time: " << sim_seconds << " s" << std::endl;
      gzdbg << "  Real Time: " << real_seconds << " s" << std::endl;

      // Reset for next period
      this->update_count = 0;
      this->total_update_time = 0.0;
    }

    private: physics::WorldPtr world;
    private: physics::PhysicsEnginePtr physics;
    private: std::chrono::high_resolution_clock::time_point start_time;
    private: std::chrono::high_resolution_clock::time_point last_update;
    private: event::ConnectionPtr update_connection;
    private: event::ConnectionPtr timer_connection;
    private: double update_rate;
    private: int update_count;
    private: double total_update_time;
  };

  GZ_REGISTER_WORLD_PLUGIN(ComprehensivePerformanceMonitor)
}
```

#### Sensor Filtering

Implement sensor filtering for performance:

```cpp
// Sensor data filtering for performance
class OptimizedSensorFilter
{
  public:
    OptimizedSensorFilter() : nh("~")
    {
      // Subscribe to raw sensor data
      raw_sub = nh.subscribe("raw_sensor_data", 1,
          &OptimizedSensorFilter::rawDataCallback, this);

      // Publish filtered data
      filtered_pub = nh.advertise<sensor_msgs::LaserScan>("filtered_scan", 1);

      // Set filter parameters
      nh.param<double>("filter_frequency", filter_freq, 10.0);
      nh.param<double>("downsampling_factor", downsampling_factor, 2.0);

      // Initialize filter timer
      filter_timer = nh.createTimer(ros::Duration(1.0/filter_freq),
          &OptimizedSensorFilter::filterCallback, this);
    }

  private:
    void rawDataCallback(const sensor_msgs::LaserScan::ConstPtr& msg)
    {
      // Store raw data for filtering
      latest_raw_data = *msg;
      data_available = true;
    }

    void filterCallback(const ros::TimerEvent& event)
    {
      if (data_available)
      {
        sensor_msgs::LaserScan filtered_msg = applyFilter(latest_raw_data);
        filtered_pub.publish(filtered_msg);
        data_available = false;
      }
    }

    sensor_msgs::LaserScan applyFilter(const sensor_msgs::LaserScan& raw)
    {
      sensor_msgs::LaserScan filtered = raw;

      // Apply downsampling for performance
      std::vector<float> downsampled_ranges;
      for (size_t i = 0; i < raw.ranges.size(); i += static_cast<int>(downsampling_factor))
      {
        downsampled_ranges.push_back(raw.ranges[i]);
      }
      filtered.ranges = downsampled_ranges;

      // Update message parameters
      filtered.angle_increment *= downsampling_factor;
      filtered.range_min = *std::min_element(filtered.ranges.begin(), filtered.ranges.end());
      filtered.range_max = *std::max_element(filtered.ranges.begin(), filtered.ranges.end());

      return filtered;
    }

  private:
    ros::NodeHandle nh;
    ros::Subscriber raw_sub;
    ros::Publisher filtered_pub;
    ros::Timer filter_timer;
    sensor_msgs::LaserScan latest_raw_data;
    bool data_available = false;
    double filter_freq;
    double downsampling_factor;
};
```

## Performance Analysis Framework

### Automated Performance Testing

Create automated performance testing framework:

```python
#!/usr/bin/env python3
"""
Automated performance testing framework for Gazebo simulations
"""
import rospy
import roslaunch
import subprocess
import time
import psutil
import matplotlib.pyplot as plt
from std_msgs.msg import Float64
from gazebo_msgs.msg import PerformanceMetrics

class PerformanceAnalyzer:
    def __init__(self):
        rospy.init_node('performance_analyzer', anonymous=True)

        # Performance data storage
        self.metrics = {
            'rtf': [],
            'cpu_percent': [],
            'memory_percent': [],
            'time': []
        }

        # Launch file paths
        self.launch_files = []

        # Subscribe to performance metrics
        rospy.Subscriber('/gazebo/performance_metrics',
                        PerformanceMetrics, self.metrics_callback)

    def metrics_callback(self, msg):
        """Callback for performance metrics"""
        current_time = rospy.Time.now().to_sec()

        self.metrics['rtf'].append(msg.real_time_factor)
        self.metrics['time'].append(current_time)

        # Get system metrics
        self.metrics['cpu_percent'].append(psutil.cpu_percent())
        self.metrics['memory_percent'].append(psutil.virtual_memory().percent)

    def run_performance_test(self, launch_file, test_duration=60):
        """Run performance test with specified launch file"""
        # Start launch file
        uuid = roslaunch.rlutil.get_or_generate_uuid(None, False)
        roslaunch.configure_logging(uuid)

        launch = roslaunch.parent.ROSLaunchParent(uuid, [launch_file])
        launch.start()

        # Monitor performance for specified duration
        start_time = time.time()
        while time.time() - start_time < test_duration:
            time.sleep(1)

        # Stop launch
        launch.shutdown()

        # Return performance data
        return self.metrics

    def compare_configurations(self, config_files, test_duration=60):
        """Compare performance across different configurations"""
        results = {}

        for config_name, launch_file in config_files.items():
            print(f"Testing configuration: {config_name}")
            results[config_name] = self.run_performance_test(launch_file, test_duration)

        return results

    def generate_report(self, results):
        """Generate performance comparison report"""
        fig, axes = plt.subplots(2, 2, figsize=(15, 10))

        for config_name, data in results.items():
            # RTF over time
            axes[0, 0].plot(data['time'], data['rtf'], label=config_name)
            axes[0, 0].set_title('Real-time Factor Over Time')
            axes[0, 0].set_xlabel('Time (s)')
            axes[0, 0].set_ylabel('RTF')
            axes[0, 0].legend()
            axes[0, 0].grid(True)

            # CPU usage
            axes[0, 1].plot(data['time'], data['cpu_percent'], label=config_name)
            axes[0, 1].set_title('CPU Usage Over Time')
            axes[0, 1].set_xlabel('Time (s)')
            axes[0, 1].set_ylabel('CPU %')
            axes[0, 1].legend()
            axes[0, 1].grid(True)

            # Memory usage
            axes[1, 0].plot(data['time'], data['memory_percent'], label=config_name)
            axes[1, 0].set_title('Memory Usage Over Time')
            axes[1, 0].set_xlabel('Time (s)')
            axes[1, 0].set_ylabel('Memory %')
            axes[1, 0].legend()
            axes[1, 0].grid(True)

        # Summary statistics
        summary_data = []
        labels = []
        for config_name, data in results.items():
            avg_rtf = sum(data['rtf']) / len(data['rtf']) if data['rtf'] else 0
            avg_cpu = sum(data['cpu_percent']) / len(data['cpu_percent']) if data['cpu_percent'] else 0
            summary_data.extend([avg_rtf, avg_cpu])
            labels.extend([f'{config_name}_RTF', f'{config_name}_CPU'])

        axes[1, 1].bar(labels, summary_data)
        axes[1, 1].set_title('Average Performance Metrics')
        axes[1, 1].set_ylabel('Value')
        plt.xticks(rotation=45)

        plt.tight_layout()
        plt.savefig('performance_comparison.png')
        plt.show()

        return fig

if __name__ == '__main__':
    analyzer = PerformanceAnalyzer()

    # Define configurations to test
    configs = {
        'default': '/path/to/default_config.launch',
        'optimized': '/path/to/optimized_config.launch',
        'high_performance': '/path/to/high_performance_config.launch'
    }

    # Run comparison
    results = analyzer.compare_configurations(configs)

    # Generate report
    analyzer.generate_report(results)
```

```cpp
// Performance benchmarking class
class SimulationBenchmark
{
  public:
    SimulationBenchmark() : nh("~")
    {
      // Initialize benchmark parameters
      nh.param<int>("benchmark_iterations", iterations, 1000);
      nh.param<double>("benchmark_duration", duration, 60.0);
      nh.param<std::string>("output_file", output_file, "benchmark_results.csv");
    }

    void runBenchmark()
    {
      // Start timing
      auto start_time = std::chrono::high_resolution_clock::now();

      // Run benchmark iterations
      for (int i = 0; i < iterations; ++i)
      {
        runSingleIteration();

        // Report progress
        if (i % 100 == 0)
        {
          ROS_INFO("Benchmark iteration %d/%d completed", i, iterations);
        }
      }

      // End timing
      auto end_time = std::chrono::high_resolution_clock::now();
      auto total_duration = std::chrono::duration_cast<std::chrono::milliseconds>(
          end_time - start_time);

      // Collect system metrics
      SystemMetrics metrics = collectSystemMetrics();

      // Calculate performance metrics
      PerformanceResults results;
      results.total_time_ms = total_duration.count();
      results.iterations_per_second = iterations / (total_duration.count() / 1000.0);
      results.cpu_usage = metrics.cpu_percent;
      results.memory_usage = metrics.memory_percent;

      // Save results
      saveResults(results);
    }

  private:
    void runSingleIteration()
    {
      // Perform single simulation iteration
      // This could involve physics updates, sensor processing, etc.
    }

    SystemMetrics collectSystemMetrics()
    {
      SystemMetrics metrics;

      // Collect CPU usage
      metrics.cpu_percent = psutil::cpu_percent();

      // Collect memory usage
      auto memory_info = psutil::virtual_memory();
      metrics.memory_percent = memory_info.percent;

      // Collect other metrics as needed
      metrics.process_count = psutil::process_count();

      return metrics;
    }

    void saveResults(const PerformanceResults& results)
    {
      // Save results to file
      std::ofstream file(output_file);
      file << "metric,value\n";
      file << "total_time_ms," << results.total_time_ms << "\n";
      file << "iterations_per_second," << results.iterations_per_second << "\n";
      file << "cpu_usage_percent," << results.cpu_usage << "\n";
      file << "memory_usage_percent," << results.memory_usage << "\n";
      file.close();
    }

  private:
    ros::NodeHandle nh;
    int iterations;
    double duration;
    std::string output_file;
};
```

### Regression Testing

Implement regression testing for performance changes:

```bash
#!/bin/bash
# Performance regression test script

# Define test configurations
CONFIGURATIONS=("default" "optimized" "legacy")

# Define test metrics
METRICS=("rtf" "cpu" "memory" "accuracy")

# Run tests for each configuration
for config in "${CONFIGURATIONS[@]}"; do
    echo "Testing configuration: $config"

    # Start Gazebo with configuration
    roslaunch my_robot_gazebo "${config}_config.launch" &
    GAZEBO_PID=$!

    # Monitor performance for 60 seconds
    for i in {1..60}; do
        # Collect metrics
        RTF=$(gz stats | grep -o "Real Time Factor: [0-9.]*" | cut -d' ' -f3)
        CPU=$(ps -p $GAZEBO_PID -o %cpu --no-headers)

        echo "$(date),${config},${RTF},${CPU},${MEMORY}" >> performance_log.csv

        sleep 1
    done

    # Kill Gazebo
    kill $GAZEBO_PID
done
```

## Best Practices for Performance Optimization

### Incremental Optimization

1. **Baseline Measurement**: Always measure baseline performance before optimization
2. **One Change at a Time**: Change one parameter at a time to understand impact
3. **Validate Results**: Ensure optimizations don't compromise simulation quality
4. **Document Changes**: Keep detailed records of all optimizations

### Monitoring and Maintenance

1. **Continuous Monitoring**: Implement ongoing performance monitoring
