# URDF and Xacro Fundamentals

The Unified Robot Description Format (URDF) and its extension Xacro form the foundation of robot modeling in ROS/ROS2 environments. This chapter covers the essential concepts, syntax, and best practices for creating accurate and efficient robot models for simulation.

## Understanding URDF

### URDF Structure and Components

URDF (Unified Robot Description Format) is an XML-based format that describes robot structure, kinematics, and dynamics. The basic structure consists of:

- **Links**: Rigid bodies that make up the robot
- **Joints**: Connections between links that define motion
- **Materials**: Visual properties for rendering
- **Gazebo Tags**: Simulation-specific properties

### Basic URDF Elements

#### Robot Element

The root element of every URDF file:

```xml
<?xml version="1.0"?>
<robot name="my_robot" xmlns:xacro="http://www.ros.org/wiki/xacro">
  <!-- Robot content goes here -->
</robot>
```

#### Link Element

Links represent rigid bodies in the robot structure:

```xml
<link name="link_name">
  <!-- Inertial properties for physics simulation -->
  <inertial>
    <mass value="1.0"/>
    <origin xyz="0 0 0.1" rpy="0 0 0"/>
    <inertia ixx="0.01" ixy="0.0" ixz="0.0" iyy="0.01" iyz="0.0" izz="0.01"/>
  </inertial>

  <!-- Visual properties for rendering -->
  <visual>
    <origin xyz="0 0 0" rpy="0 0 0"/>
    <geometry>
      <box size="0.1 0.1 0.1"/>
    </geometry>
    <material name="blue">
      <color rgba="0 0 1 1"/>
    </material>
  </visual>

  <!-- Collision properties for physics -->
  <collision>
    <origin xyz="0 0 0" rpy="0 0 0"/>
    <geometry>
      <box size="0.1 0.1 0.1"/>
    </geometry>
  </collision>
</link>
```

#### Joint Element

Joints define the connections between links:

```xml
<joint name="joint_name" type="revolute">
  <parent link="parent_link"/>
  <child link="child_link"/>
  <origin xyz="0 0 0.1" rpy="0 0 0"/>
  <axis xyz="0 0 1"/>
  <limit lower="-1.57" upper="1.57" effort="100.0" velocity="2.0"/>
  <dynamics damping="1.0" friction="0.1"/>
</joint>
```

### Joint Types

URDF supports several joint types, each serving different purposes:

#### Fixed Joint
```xml
<joint name="fixed_joint" type="fixed">
  <parent link="parent_link"/>
  <child link="child_link"/>
  <origin xyz="0.1 0 0" rpy="0 0 0"/>
</joint>
```

#### Revolute Joint
```xml
<joint name="revolute_joint" type="revolute">
  <parent link="parent_link"/>
  <child link="child_link"/>
  <origin xyz="0 0 0" rpy="0 0 0"/>
  <axis xyz="0 0 1"/>
  <limit lower="-3.14" upper="3.14" effort="50.0" velocity="1.0"/>
</joint>
```

#### Continuous Joint
```xml
<joint name="continuous_joint" type="continuous">
  <parent link="parent_link"/>
  <child link="child_link"/>
  <origin xyz="0 0 0" rpy="0 0 0"/>
  <axis xyz="0 0 1"/>
</joint>
```

#### Prismatic Joint
```xml
<joint name="prismatic_joint" type="prismatic">
  <parent link="parent_link"/>
  <child link="child_link"/>
  <origin xyz="0 0 0" rpy="0 0 0"/>
  <axis xyz="1 0 0"/>
  <limit lower="0" upper="0.5" effort="100.0" velocity="0.5"/>
</joint>
```

## Inertial Properties

### Mass and Center of Mass

Proper inertial properties are crucial for realistic physics simulation:

```xml
<inertial>
  <mass value="2.5"/>  <!-- Mass in kilograms -->
  <origin xyz="0.01 0.02 0.03" rpy="0 0 0"/>  <!-- Center of mass offset -->
  <inertia ixx="0.01" ixy="0.001" ixz="0.002" iyy="0.02" iyz="0.003" izz="0.03"/>
</inertial>
```

### Calculating Inertia

For common geometric shapes:

#### Box
```xml
<!-- For a box with mass m, width w, depth d, height h -->
<!-- ixx = m*(d² + h²)/12, iyy = m*(w² + h²)/12, izz = m*(w² + d²)/12 -->
<inertial>
  <mass value="1.0"/>
  <inertia ixx="0.00833" ixy="0" ixz="0" iyy="0.00833" iyz="0" izz="0.00833"/>
</inertial>
```

#### Cylinder
```xml
<!-- For a cylinder with mass m, radius r, height h -->
<!-- ixx = m*(3*r² + h²)/12, iyy = m*(3*r² + h²)/12, izz = m*r²/2 -->
<inertial>
  <mass value="1.0"/>
  <inertia ixx="0.0125" ixy="0" ixz="0" iyy="0.0125" iyz="0" izz="0.01"/>
</inertial>
```

#### Sphere
```xml
<!-- For a sphere with mass m, radius r -->
<!-- ixx = iyy = izz = 2*m*r²/5 -->
<inertial>
  <mass value="1.0"/>
  <inertia ixx="0.008" ixy="0" ixz="0" iyy="0.008" iyz="0" izz="0.008"/>
</inertial>
```

## Visual and Collision Properties

### Geometry Types

URDF supports several geometry types for both visual and collision elements:

#### Box
```xml
<geometry>
  <box size="0.1 0.2 0.3"/>  <!-- width depth height -->
</geometry>
```

#### Cylinder
```xml
<geometry>
  <cylinder radius="0.05" length="0.1"/>  <!-- radius and length -->
</geometry>
```

#### Sphere
```xml
<geometry>
  <sphere radius="0.05"/>  <!-- radius -->
</geometry>
```

#### Mesh
```xml
<geometry>
  <mesh filename="package://my_robot_description/meshes/link.dae" scale="1 1 1"/>
</geometry>
```

### Material Properties

Define materials for visual rendering:

```xml
<material name="red">
  <color rgba="1 0 0 1"/>  <!-- Red, Green, Blue, Alpha -->
</material>

<material name="blue">
  <color rgba="0 0 1 1"/>
</material>

<material name="custom_material">
  <color rgba="0.5 0.5 0.5 1"/>
  <texture filename="package://my_robot_description/textures/texture.png"/>
</material>
```

## Introduction to Xacro

### Xacro Benefits

Xacro (XML Macros) extends URDF with programming-like features:
- **Macros**: Reusable components for common structures
- **Properties**: Parameterized values for flexibility
- **Mathematical Expressions**: Calculations within the model
- **Inclusion**: Modular organization of complex models

### Basic Xacro Elements

#### Properties

Define reusable values:

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="my_robot">
  <!-- Define properties -->
  <xacro:property name="M_PI" value="3.1415926535897931"/>
  <xacro:property name="wheel_radius" value="0.05"/>
  <xacro:property name="wheel_width" value="0.02"/>
  <xacro:property name="robot_mass" value="10.0"/>

  <!-- Use properties in calculations -->
  <link name="wheel">
    <inertial>
      <mass value="${robot_mass * 0.1}"/>
      <inertia ixx="${robot_mass * 0.1 * (3 * wheel_radius * wheel_radius + wheel_width * wheel_width) / 12}"
               ixy="0" ixz="0"
               iyy="${robot_mass * 0.1 * (3 * wheel_radius * wheel_radius + wheel_width * wheel_width) / 12}"
               iyz="0"
               izz="${robot_mass * 0.1 * wheel_radius * wheel_radius / 2}"/>
    </inertial>
  </link>
</robot>
```

#### Macros

Create reusable components:

```xml
<!-- Define a macro for creating a wheel -->
<xacro:macro name="wheel_macro" params="name parent xyz radius width mass">
  <joint name="${name}_joint" type="continuous">
    <parent link="${parent}"/>
    <child link="${name}_link"/>
    <origin xyz="${xyz}" rpy="0 0 0"/>
    <axis xyz="0 1 0"/>
  </joint>

  <link name="${name}_link">
    <inertial>
      <mass value="${mass}"/>
      <origin xyz="0 0 0" rpy="0 0 0"/>
      <inertia ixx="${mass * (3 * radius * radius + width * width) / 12}"
               ixy="0" ixz="0"
               iyy="${mass * (3 * radius * radius + width * width) / 12}"
               iyz="0"
               izz="${mass * radius * radius / 2}"/>
    </inertial>

    <visual>
      <origin xyz="0 0 0" rpy="0 1.57079632679 0"/>
      <geometry>
        <cylinder radius="${radius}" length="${width}"/>
      </geometry>
    </visual>

    <collision>
      <origin xyz="0 0 0" rpy="0 1.57079632679 0"/>
      <geometry>
        <cylinder radius="${radius}" length="${width}"/>
      </geometry>
    </collision>
  </link>
</xacro:macro>

<!-- Use the macro to create wheels -->
<xacro:wheel_macro name="front_left" parent="base_link" xyz="0.2 0.15 0" radius="0.05" width="0.02" mass="0.5"/>
<xacro:wheel_macro name="front_right" parent="base_link" xyz="0.2 -0.15 0" radius="0.05" width="0.02" mass="0.5"/>
<xacro:wheel_macro name="rear_left" parent="base_link" xyz="-0.2 0.15 0" radius="0.05" width="0.02" mass="0.5"/>
<xacro:wheel_macro name="rear_right" parent="base_link" xyz="-0.2 -0.15 0" radius="0.05" width="0.02" mass="0.5"/>
```

### Mathematical Expressions

Xacro supports mathematical operations:

```xml
<xacro:property name="base_length" value="0.3"/>
<xacro:property name="base_width" value="0.3"/>
<xacro:property name="base_height" value="0.2"/>
<xacro:property name="base_mass" value="10.0"/>

<!-- Calculate derived properties -->
<xacro:property name="base_ixx" value="${base_mass * (base_width * base_width + base_height * base_height) / 12}"/>
<xacro:property name="base_iyy" value="${base_mass * (base_length * base_length + base_height * base_height) / 12}"/>
<xacro:property name="base_izz" value="${base_mass * (base_length * base_length + base_width * base_width) / 12}"/>

<link name="base_link">
  <inertial>
    <mass value="${base_mass}"/>
    <origin xyz="0 0 0.1" rpy="0 0 0"/>
    <inertia ixx="${base_ixx}" ixy="0" ixz="0" iyy="${base_iyy}" iyz="0" izz="${base_izz}"/>
  </inertial>
</link>
```

### Conditional Statements

Xacro supports conditional processing:

```xml
<xacro:property name="with_camera" value="true"/>

<xacro:if value="${with_camera}">
  <link name="camera_link">
    <visual>
      <geometry>
        <box size="0.05 0.05 0.05"/>
      </geometry>
    </visual>
  </link>

  <joint name="camera_joint" type="fixed">
    <parent link="base_link"/>
    <child link="camera_link"/>
    <origin xyz="0.1 0 0.1" rpy="0 0 0"/>
  </joint>
</xacro:if>

<xacro:unless value="${with_camera}">
  <!-- Alternative configuration when no camera is needed -->
</xacro:unless>
```

## Advanced Xacro Techniques

### Including Other Files

Organize complex models by including separate files:

```xml
<!-- Main robot file -->
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="humanoid_robot">
  <!-- Include common properties -->
  <xacro:include filename="$(find my_robot_description)/urdf/common_properties.urdf.xacro"/>

  <!-- Include specific components -->
  <xacro:include filename="$(find my_robot_description)/urdf/base.urdf.xacro"/>
  <xacro:include filename="$(find my_robot_description)/urdf/arms.urdf.xacro"/>
  <xacro:include filename="$(find my_robot_description)/urdf/legs.urdf.xacro"/>
  <xacro:include filename="$(find my_robot_description)/urdf/sensors.urdf.xacro"/>

  <!-- Instantiate components -->
  <xacro:base_macro/>
  <xacro:arms_macro/>
  <xacro:legs_macro/>
  <xacro:sensors_macro/>
</robot>
```

### Nested Macros

Create complex hierarchical structures:

```xml
<xacro:macro name="arm_macro" params="side parent xyz">
  <link name="${side}_shoulder_link">
    <inertial>
      <mass value="1.0"/>
      <inertia ixx="0.01" ixy="0" ixz="0" iyy="0.01" iyz="0" izz="0.01"/>
    </inertial>
  </link>

  <joint name="${side}_shoulder_joint" type="revolute">
    <parent link="${parent}"/>
    <child link="${side}_shoulder_link"/>
    <origin xyz="${xyz}" rpy="0 0 0"/>
    <axis xyz="0 0 1"/>
    <limit lower="-1.57" upper="1.57" effort="50.0" velocity="2.0"/>
  </joint>

  <!-- Include hand component -->
  <xacro:include filename="$(find my_robot_description)/urdf/hand.urdf.xacro"/>
  <xacro:hand_macro side="${side}" parent="${side}_shoulder_link" xyz="0.2 0 0"/>
</xacro:macro>
```

### Namespaces

Use namespaces to avoid naming conflicts:

```xml
<xacro:macro name="robot_with_namespace" params="prefix">
  <link name="${prefix}_base_link">
    <inertial>
      <mass value="5.0"/>
      <inertia ixx="0.1" ixy="0" ixz="0" iyy="0.1" iyz="0" izz="0.1"/>
    </inertial>
  </link>

  <joint name="${prefix}_base_joint" type="fixed">
    <parent link="world"/>
    <child link="${prefix}_base_link"/>
  </joint>
</xacro:macro>

<!-- Use the macro with different prefixes -->
<xacro:robot_with_namespace prefix="robot1"/>
<xacro:robot_with_namespace prefix="robot2"/>
```

## Best Practices for URDF/Xacro

### Organization and Structure

1. **Modular Design**: Break complex robots into logical components
2. **Consistent Naming**: Use clear, descriptive names for links and joints
3. **Parameterization**: Use properties for values that might change
4. **Documentation**: Comment complex sections and explain parameter choices

### Performance Considerations

1. **Simplified Collision Geometry**: Use primitive shapes instead of complex meshes
2. **Appropriate Detail**: Balance visual quality with computational efficiency
3. **Efficient Macros**: Avoid overly complex nested macros that are hard to debug

### Validation Techniques

1. **Syntax Checking**: Use `check_urdf` command to validate structure
2. **Visualization**: Use RViz to verify model structure and kinematics
3. **Kinematic Testing**: Use `joint_state_publisher` to test joint ranges
4. **Physics Validation**: Test in Gazebo to verify dynamic behavior

## Common URDF/Xacro Pitfalls

### Inertia Issues

- **Zero Inertia Values**: Always provide non-zero inertia values
- **Incorrect Signs**: Ensure inertia values are positive
- **Massless Links**: Every link should have a mass value

### Joint Configuration

- **Missing Limits**: Revolute joints should have position limits
- **Invalid Ranges**: Ensure joint limits are physically achievable
- **Incorrect Axes**: Verify joint axis directions are correct

### Coordinate Systems

- **Consistent Frames**: Maintain consistent coordinate system orientations
- **Proper Origins**: Ensure joint origins are correctly specified
- **Transform Chains**: Verify all links are properly connected

### File Management

- **Path Issues**: Use proper package:// syntax for file references
- **Circular Dependencies**: Avoid include statements that create loops
- **Namespace Conflicts**: Use prefixes to avoid naming conflicts

Understanding URDF and Xacro fundamentals is essential for creating effective robot models. These tools provide the foundation for representing robots in simulation environments and enable the development of complex humanoid robotics systems.
