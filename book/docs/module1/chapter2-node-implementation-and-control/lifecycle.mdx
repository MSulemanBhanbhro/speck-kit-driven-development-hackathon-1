# Node Lifecycle Management

## Introduction to Lifecycle Nodes

Lifecycle nodes in ROS 2 provide a structured approach to managing the state and behavior of nodes throughout their operational lifetime. Unlike regular nodes that start and run continuously, lifecycle nodes follow a well-defined state machine that allows for more sophisticated control over initialization, activation, deactivation, and cleanup processes. This is particularly important in robotic systems where nodes need to coordinate their states with other system components.

According to the ROS 2 documentation, lifecycle nodes address the challenge of managing complex robotic systems where components need to be initialized in a specific order, activated when needed, and deactivated safely when not in use (ROS.org, 2023). This approach enhances system reliability and maintainability.

## Lifecycle Node States

### State Machine Overview

Lifecycle nodes follow a finite state machine with the following states:

1. **Unconfigured**: The node is created but not yet configured
2. **Inactive**: The node is configured but not yet active
3. **Active**: The node is running and processing data
4. **Activating**: Transitioning from Inactive to Active
5. **Deactivating**: Transitioning from Active to Inactive
6. **Cleaning up**: Transitioning from Inactive to Unconfigured
7. **Shutting down**: Transitioning from any state to finalize
8. **Error processing**: Handling errors during state transitions

### State Transition Diagram

```
[Unconfigured] ←→ [Inactive] ←→ [Active]
     ↓                 ↓           ↓
[Cleaning up] → [Shutting down] [Deactivating]
                        ↓
[Error processing] ←→ [Unconfigured]
```

## Implementing Lifecycle Nodes

### Basic Lifecycle Node Structure

```python
import rclpy
from rclpy.lifecycle import LifecycleNode, LifecycleState, TransitionCallbackReturn
from rclpy.lifecycle import Node as rclpy_Node
from std_msgs.msg import String

class BasicLifecycleNode(LifecycleNode):
    def __init__(self):
        super().__init__('basic_lifecycle_node')
        self.get_logger().info('Lifecycle node initialized in unconfigured state')

    def on_configure(self, state):
        """
        Called when transitioning to configuring state.

        Args:
            state: The current state before transition

        Returns:
            TransitionCallbackReturn: SUCCESS, FAILURE, or ERROR
        """
        self.get_logger().info(f'Configuring node: {self.get_name()}')

        # Initialize resources that don't require active communication
        try:
            # Create publishers and subscribers but don't activate them yet
            self.pub = self.create_publisher(String, 'lifecycle_topic', 10)
            self.timer = self.create_timer(1.0, self.timer_callback)

            # Deactivate timer initially
            self.timer.cancel()

            self.get_logger().info('Node configured successfully')
            return TransitionCallbackReturn.SUCCESS

        except Exception as e:
            self.get_logger().error(f'Failed to configure node: {e}')
            return TransitionCallbackReturn.FAILURE

    def on_cleanup(self, state):
        """
        Called when transitioning to cleaning up state.

        Args:
            state: The current state before transition

        Returns:
            TransitionCallbackReturn: SUCCESS, FAILURE, or ERROR
        """
        self.get_logger().info(f'Cleaning up node: {self.get_name()}')

        try:
            # Clean up resources created during configuration
            if hasattr(self, 'timer') and self.timer is not None:
                self.timer.destroy()

            self.get_logger().info('Node cleaned up successfully')
            return TransitionCallbackReturn.SUCCESS

        except Exception as e:
            self.get_logger().error(f'Failed to clean up node: {e}')
            return TransitionCallbackReturn.FAILURE

    def on_activate(self, state):
        """
        Called when transitioning to activating state.

        Args:
            state: The current state before transition

        Returns:
            TransitionCallbackReturn: SUCCESS, FAILURE, or ERROR
        """
        self.get_logger().info(f'Activating node: {self.get_name()}')

        try:
            # Activate publishers and subscribers
            self.pub.on_activate()

            # Start timer
            if hasattr(self, 'timer') and self.timer is not None:
                self.timer.reset()

            self.get_logger().info('Node activated successfully')
            return TransitionCallbackReturn.SUCCESS

        except Exception as e:
            self.get_logger().error(f'Failed to activate node: {e}')
            return TransitionCallbackReturn.FAILURE

    def on_deactivate(self, state):
        """
        Called when transitioning to deactivating state.

        Args:
            state: The current state before transition

        Returns:
            TransitionCallbackReturn: SUCCESS, FAILURE, or ERROR
        """
        self.get_logger().info(f'Deactivating node: {self.get_name()}')

        try:
            # Deactivate publishers and subscribers
            if hasattr(self, 'pub'):
                self.pub.on_deactivate()

            # Stop timer
            if hasattr(self, 'timer') and self.timer is not None:
                self.timer.cancel()

            self.get_logger().info('Node deactivated successfully')
            return TransitionCallbackReturn.SUCCESS

        except Exception as e:
            self.get_logger().error(f'Failed to deactivate node: {e}')
            return TransitionCallbackReturn.FAILURE

    def on_shutdown(self, state):
        """
        Called when transitioning to shutdown state.

        Args:
            state: The current state before transition

        Returns:
            TransitionCallbackReturn: SUCCESS, FAILURE, or ERROR
        """
        self.get_logger().info(f'Shutting down node: {self.get_name()}')

        try:
            # Perform final cleanup
            if hasattr(self, 'timer') and self.timer is not None:
                self.timer.destroy()

            self.get_logger().info('Node shutdown successfully')
            return TransitionCallbackReturn.SUCCESS

        except Exception as e:
            self.get_logger().error(f'Failed during shutdown: {e}')
            return TransitionCallbackReturn.FAILURE

    def timer_callback(self):
        """Timer callback that only executes when node is active."""
        msg = String()
        msg.data = f'Hello from lifecycle node: {self.get_clock().now().nanoseconds}'
        self.pub.publish(msg)
        self.get_logger().info(f'Published: {msg.data}')
```

## Managing Lifecycle Nodes

### Using Lifecycle Manager

ROS 2 provides a lifecycle manager to control multiple lifecycle nodes:

```python
import rclpy
from rclpy.lifecycle import LifecycleNode
from lifecycle_msgs.srv import ChangeState, GetState
from lifecycle_msgs.msg import Transition
from rclpy.qos import qos_profile_services_default

class LifecycleManagerNode(LifecycleNode):
    def __init__(self):
        super().__init__('lifecycle_manager')

        # Node to manage
        self.node_to_manage = 'managed_node'

        # Create clients for lifecycle services
        self.change_state_client = self.create_client(
            ChangeState,
            f'{self.node_to_manage}/change_state',
            qos_profile=qos_profile_services_default
        )

        self.get_state_client = self.create_client(
            GetState,
            f'{self.node_to_manage}/get_state',
            qos_profile=qos_profile_services_default
        )

        # Wait for services to be available
        while not self.change_state_client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('Change state service not available, waiting again...')

        while not self.get_state_client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('Get state service not available, waiting again...')

        self.get_logger().info('Lifecycle manager initialized')

    def change_node_state(self, transition_id):
        """
        Change the state of the managed node.

        Args:
            transition_id: The ID of the transition to execute

        Returns:
            The response from the change state service
        """
        request = ChangeState.Request()
        request.transition.id = transition_id

        future = self.change_state_client.call_async(request)
        return future

    def get_node_state(self):
        """
        Get the current state of the managed node.

        Returns:
            The response from the get state service
        """
        request = GetState.Request()

        future = self.get_state_client.call_async(request)
        return future

    def configure_node(self):
        """Configure the managed node."""
        future = self.change_node_state(Transition.TRANSITION_CONFIGURE)
        return future

    def activate_node(self):
        """Activate the managed node."""
        future = self.change_node_state(Transition.TRANSITION_ACTIVATE)
        return future

    def deactivate_node(self):
        """Deactivate the managed node."""
        future = self.change_node_state(Transition.TRANSITION_DEACTIVATE)
        return future

    def cleanup_node(self):
        """Clean up the managed node."""
        future = self.change_node_state(Transition.TRANSITION_CLEANUP)
        return future
```

## Error Handling and Recovery

### Error Processing State

```python
class ErrorHandlingLifecycleNode(LifecycleNode):
    def __init__(self):
        super().__init__('error_handling_node')
        self._error_count = 0
        self._max_errors = 3

    def on_error(self, state):
        """
        Called when an error occurs during a transition.

        Args:
            state: The current state

        Returns:
            TransitionCallbackReturn: How to handle the error
        """
        self.get_logger().error(f'Error occurred in state: {state.label}')
        self._error_count += 1

        if self._error_count >= self._max_errors:
            self.get_logger().error('Maximum error count reached, shutting down')
            return TransitionCallbackReturn.ERROR
        else:
            self.get_logger().info(f'Error count: {self._error_count}, attempting recovery')
            # Try to recover from error
            return TransitionCallbackReturn.SUCCESS

    def on_configure(self, state):
        """Configure with error checking."""
        try:
            # Attempt configuration
            self._configure_resources()
            self._error_count = 0  # Reset error count on success
            return TransitionCallbackReturn.SUCCESS
        except Exception as e:
            self.get_logger().error(f'Configuration error: {e}')
            return TransitionCallbackReturn.FAILURE

    def _configure_resources(self):
        """Configure resources with error handling."""

            raise Exception("Simulated configuration error")
```

```python
class BestPracticeLifecycleNode(LifecycleNode):

        try:
            # Initialize resources
            self._resources['publisher'] = self.create_publisher(String, 'topic', 10)
            self._resources['timer'] = self.create_timer(1.0, self._timer_callback)
            self._resources['timer'].cancel()  # Don't start yet

            # Validate resources exist

                self.get_logger().error('Required resources not available')
                return TransitionCallbackReturn.FAILURE

            # Activate resources
            self._resources['publisher'].on_activate()
            self._resources['timer'].reset()
```

### Sensor Node Lifecycle

```python
from sensor_msgs.msg import JointState

class SensorLifecycleNode(LifecycleNode):
    def __init__(self):
        super().__init__('sensor_lifecycle_node')
        self._sensor_interface = None

    def on_configure(self, state):
        """Configure sensor interface."""
        try:
            # Initialize sensor interface
            self._sensor_interface = self._initialize_sensor()

            # Create publisher for sensor data
            self._sensor_pub = self.create_publisher(JointState, 'joint_states', 10)

            return TransitionCallbackReturn.SUCCESS
        except Exception as e:
            self.get_logger().error(f'Sensor configuration failed: {e}')
            return TransitionCallbackReturn.FAILURE

    def on_activate(self, state):
        """Start sensor data acquisition."""
        try:
            if self._sensor_interface:
                self._sensor_interface.start()

            # Start timer to publish sensor data
            self._sensor_timer = self.create_timer(0.05, self._publish_sensor_data)  # 20 Hz

            return TransitionCallbackReturn.SUCCESS
        except Exception as e:
            self.get_logger().error(f'Sensor activation failed: {e}')
            return TransitionCallbackReturn.FAILURE

    def on_deactivate(self, state):
        """Stop sensor data acquisition."""
        try:
            if hasattr(self, '_sensor_timer'):
                self._sensor_timer.cancel()

            if self._sensor_interface:
                self._sensor_interface.stop()

            return TransitionCallbackReturn.SUCCESS
        except Exception as e:
            self.get_logger().error(f'Sensor deactivation failed: {e}')
            return TransitionCallbackReturn.FAILURE

    def _initialize_sensor(self):
        """Initialize the sensor interface."""
        # Initialize actual sensor here
        class MockSensor:
            def start(self): pass
            def stop(self): pass
            def read(self): return [0.0, 0.0, 0.0]  # Mock joint positions
        return MockSensor()

    def _publish_sensor_data(self):
        """Publish sensor data."""
        if self._sensor_interface:
            joint_positions = self._sensor_interface.read()

            msg.name = ['joint1', 'joint2', 'joint3']

            msg.header.stamp = self.get_clock().now().to_msg()

            self._sensor_pub.publish(msg)
```

## Summary

Lifecycle nodes provide a powerful framework for managing complex robotic systems with proper state management, resource handling, and error recovery. By following the structured state machine approach, lifecycle nodes enable more robust and maintainable robotic applications. The ability to configure, activate, deactivate, and clean up resources in a controlled manner is essential for reliable robotic systems that need to operate in dynamic environments.

Understanding and implementing lifecycle nodes is crucial for developing professional-grade ROS 2 applications that can handle the complexities of real-world robotic systems.
