## Conceptual Relationships

### Communication Patterns Hierarchy
1. **Topics** (Chapter 1) - Basic publish/subscribe
2. **Services** (Chapter 1) - Request/response
3. **Actions** (Chapter 4) - Long-running with feedback

### Node Complexity Progression
1. **Basic Nodes** (Chapter 1) - Simple publishers/subscribers
2. **Control Nodes** (Chapter 2) - Service-based control
3. **Lifecycle Nodes** (Chapter 4) - Advanced state management

### Robot Modeling Integration
- **URDF/XACRO** (Chapter 3) connects with **Node Implementation** (Chapter 2) through robot state publishing
- **Actions** (Chapter 4) can be used to control robot movements defined in **Robot Structure** (Chapter 3)

These cross-references help you understand how concepts build upon each other and where to find related information when implementing your robotic systems.
